# SPT Linux Installer

Windows-Assistent zur Installation und Verwaltung eines SPT-Servers auf Linux.

- Neueste stabile SPT-Version direkt aus der offiziellen Quelle laden.
- Verbindung über SSH mit Passwort oder privatem Schlüssel.
- Native Linux-Installation mit eigenem systemd-Dienst.
- Status, Start, Stop, Neustart, Protokoll und gesicherte Updates.
- Vorhandene SPT-Dienste mit Installationspfad und Laufstatus anzeigen.
- Dunkle, rahmenlose Windows-Oberfläche.

## Installation

`SPT-Linux-Installer-Windows-x64.zip` herunterladen, entpacken und
`SPT-Linux-Installer.exe` starten. Auf Windows ist keine zusätzliche
.NET-Installation erforderlich.

Unterstützt werden Windows 10/11 x64 sowie Ubuntu 22.04/24.04/26.04 und Debian
12/13 auf dem Linux-Server. Der SSH-Benutzer benötigt root oder sudo ohne
Passwort. Der Spielclient verbindet sich direkt mit der Serveradresse.

Das Paket enthält den Assistenten, Dokumentation und Lizenzhinweise. Es enthält
keine Mods, kein Fika und keine EFT-Spieldateien. Die SHA-256-Prüfsumme steht in
`SHA256SUMS.txt`.
